# Simple_Resume 产品需求文档

## 1. 产品定位

Simple_Resume 是一个在线简历编辑器，帮助用户快速完成简历编辑、排版预览和 PDF 导出。

当前项目由两部分组成：

- 前端编辑器：负责简历编辑、预览、排版和导出。
- 本地后端：负责安全连接 DeepSeek API，提供 AI 对话和文本润色能力。

## 2. 目标用户

- 应届生和求职者
- 需要快速制作简历的用户
- 希望用 AI 优化简历表达的用户
- 想学习前端 + AI 后端接入的个人开发者

## 3. 已实现功能

### 前端功能

- 模块化简历编辑
- 个人信息、经历、项目、技能、自我评价等内容编辑
- 模块新增、删除、隐藏和拖拽排序
- A4 简历实时预览
- 字体、字号、行高、边距和模块间距调整
- 智能铺满纸张
- 导出高清 PDF
- 本地保存
- 撤销 / 重做
- 中英文切换

### 后端功能

- Node.js + Express 本地后端
- `.env` 读取 DeepSeek API Key
- `GET /api/health` 健康检查
- `POST /api/ai/chat` AI 简历对话
- `POST /api/ai/rewrite` AI 文本润色

## 4. AI 功能逻辑

AI 功能采用以下分工：

```text
前端：收集简历内容和用户指令
后端：携带 API Key 请求 DeepSeek
DeepSeek：生成建议或优化文本
前端：展示结果，用户确认后应用到简历
```

设计原则：

- API Key 只放在后端 `.env`。
- 前端不直接请求 DeepSeek。
- AI 第一阶段只优化文本，不直接操作页面结构。
- AI 返回结果需要用户确认后再写入简历。

## 5. 当前后端接口

### 健康检查

```http
GET /api/health
```

用于确认后端是否启动、API Key 是否读取成功。

### AI 对话

```http
POST /api/ai/chat
```

用于根据当前简历内容回答问题、给出简历建议。

### AI 文本润色

```http
POST /api/ai/rewrite
```

用于根据用户要求优化某段简历文本。

## 6. 前端 AI 接入计划

下一步计划把后端 AI 能力接入页面：

- 增加 AI 助手入口
- 增加 AI 对话面板
- 支持对当前模块文本进行润色
- 展示“原文 / 优化后”对比
- 用户点击确认后再应用修改
- 应用后复用现有逻辑刷新页面：

```js
renderEditor();
renderPreview();
saveStateToLocal();
pushHistory();
```

第一版 AI 不开放：

- 新增模块
- 删除模块
- 调整模块顺序
- 修改字体和排版
- 执行 AI 返回的代码

## 7. 简历导入规划

后续计划支持用户上传已有简历并自动导入。

第一阶段支持：

- Word `.docx`
- 文本型 PDF

暂不支持：

- 扫描版 PDF
- 图片简历
- OCR 识别

导入流程：

```text
用户上传文件
  ↓
后端提取文本
  ↓
DeepSeek 提取结构化简历信息
  ↓
前端展示导入预览
  ↓
用户确认后替换当前简历
```

## 8. 安全要求

不能上传：

```text
server/.env
server/node_modules/
```

原因：

- `.env` 包含 DeepSeek API Key。
- `node_modules` 可以通过 `npm install` 重新生成。

如果 API Key 泄露，应立即在 DeepSeek 平台删除旧 Key 并重新创建。

- 支持 Word 导入
